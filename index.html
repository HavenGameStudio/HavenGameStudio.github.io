Unity WebGL Mobile browser Client · NDA

Radical Racing Game · Buko Studios

A Unity racing game for one of the Philippines' largest oil & energy companies. It runs as a WebGL build inside an iframe in the client's own app. It's under NDA, so instead of screenshots there's a diagram of how the build fits together.

Role
Senior Unity Developer, project-based, in a team of 5
Stack
Unity, C#, WebGL, .jslib browser plugins, REST API
Hard problem
Tilt steering worked in the Android build but not in WebGL, because mobile browsers block the gyroscope and orientation sensors until the page asks for permission. I wrote a .jslib plugin that has the browser request that permission from the device, so gyro steering works inside the client's app.
More detail
Integration
The game talks to the host app through a REST API, sending and receiving player data while embedded in its iframe.
Performance
Tuned to run in a phone's browser, where memory and GPU budgets are much tighter than in a native build.
Tooling
An in-editor device simulator for checking adaptive layouts without a phone, and a debugger that pinpoints where a problem happens.
Status
In internal QA, no open bugs so far
